# Casting

Moderator always present, never a seat. Seat to agent name is the same string.

| Decision type | Seats |
|---|---|
| Fix technical debt first or publish new content | seo-developer, content-strategist, pragmatist, skeptic |
| Channel mix or budget split across SEO, Google Ads, Meta | marketing-strategist, seo-analyst, google-ads-manager, meta-ads-manager, skeptic |
| Invest in AI visibility now | geo-analyst, geo-developer, marketing-strategist, skeptic |
| Which keyword cluster to own in 6 months | seo-analyst, content-strategist, pragmatist, skeptic |
| Migration or re-platform | seo-developer, seo-analyst, pragmatist, skeptic |
| Brand bidding or paid-organic overlap | google-ads-manager, seo-analyst, marketing-strategist, skeptic |
| Shopping feed versus organic product pages | google-ads-manager, content-strategist, seo-developer, skeptic |
| Pre-sales proposal for a prospect | marketing-strategist, seo-analyst, pragmatist, skeptic |

## Rules

- Seats: default 4, minimum 3, hard maximum 6.
- At least one builder (any seat except skeptic, pragmatist), the skeptic always, at least one
  counterweight (pragmatist or marketing-strategist).
- No two seats with the same remit. The user may add or drop seats between rounds; a new seat receives
  the pack and all earlier round files.
- Unlisted decision: choose by remit from the personas' descriptions, then check the rules above.
- Ads seats work from the checklist and from facts the user states (no account data tools yet); say so
  in the brief so the seat lists missing numbers under NEEDS.
