# Moderator briefs and weaving

The moderator reads files and returns text; the lead writes it to disk. Spawn it with the dispatch
brief from `schemas.md`, `Read also:` = frame and the round files.

## Pass 1 (after R1)

1. Check each `r1-<seat>.md` against its schema and word cap. List violations by seat; do not fix them.
2. If every builder position is the same, say "premature consensus" and ask for one contrarian turn of
   the pragmatist: "name the hidden assumption".
3. Return the woven R1, at most 400 words.

## Pass 2 (after R2)

1. Check schemas. If R2 repeats R1 text, say "loop".
2. Return woven R2 with each rebuttal placed after what it rebuts.
3. List surviving disagreements as: seats, topic, class (factual, value, untestable). Factual ones carry
   a NEEDS line (tool with epic tag, parameters, estimated credits from the price list).
4. Recommend R3 only for a decision-critical clash between two named seats.

## Weaving rules

- Prefix each turn with a label like `[skeptic]`; quote seats verbatim; never describe a seat in third
  person; never change substance; unequal turn lengths are fine.
- The woven text is for the user. Seats never receive it.
- Keep the rounds free of summary; the only summary is the verdict.
